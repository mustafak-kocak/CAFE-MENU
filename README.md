# ☕ MusCOFFEE - Mobil Kafe Menü Uygulaması

MusCOFFEE, Ionic ve Angular kullanılarak geliştirilmiş, modern arayüze sahip bir mobil/web kafe menüsü ve sepet yönetim uygulamasıdır.

## 🚀 Özellikler

- 📜 **Dinamik Menü Listeleme:** Kategorize edilebilir ürün listesi ve detay görünümleri.
- 🛒 **Sepet Yönetimi:** Sepete ürün ekleme, adet artırma/azaltma, ürün silme ve toplam tutar hesaplama.
- 💾 **Kalıcı Depolama (Local Storage):** Sepet verilerinin ve ürünlerin cihaz hafızasında saklanması.
- ➕ **Yönetici Paneli / Ürün Ekleme:** Modal mimarisi ile yeni ürün ekleme fonksiyonu.
- 🎨 **Modern UI/UX:** Özel sidebar tasarımı, karanlık tema uyumu, özelleştirilmiş Alert ve Toast bildirimleri.

## 🛠️ Kullanılan Teknolojiler

- **Framework:** Ionic Framework, Angular
- **Dil:** TypeScript, HTML5, SCSS
- **Editör/Araçlar:** VS Code, GitHub Copilot, Git
