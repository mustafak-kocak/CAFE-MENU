# MusCOFFEE - Mobil Kafe Menü Uygulaması

MusCOFFEE, Ionic ve Angular kullanılarak geliştirilmiş, modern arayüze sahip bir mobil ve web kafe menüsü/sepet yönetim uygulamasıdır.

## Özellikler

- Dinamik Menü Listeleme: Kategorize edilebilir ürün listesi ve detay görünümleri.
- Sepet Yönetimi: Sepete ürün ekleme, adet artırma/azaltma, ürün silme ve toplam tutar hesaplama.
- Kalıcı Depolama (Local Storage): Sepet verilerinin cihaz hafızasında saklanması.
- Yönetici Paneli / Ürün Ekleme: Yeni ürün ekleme penceresi (Modal yapısı).
- Modern Arayüz (UI/UX): Özel yan menü tasarımı, karanlık tema uyumu ve özelleştirilmiş bildirimler.

## Kullanılan Teknolojiler

- Framework: Ionic Framework, Angular
- Dil: TypeScript, HTML5, SCSS
- Araçlar: VS Code, Git, GitHub

## Bilgisayarda Çalıştırma Adımları

Projeyi kendi bilgisayarınızda çalıştırmak için:

1. Proje dosyalarını indirin:
   git clone https://github.com/mustafak-kocak/CAFE-MENU.git

2. Proje klasörüne girin:
   cd CAFE-MENU

3. Gerekli kütüphaneleri yükleyin:
   npm install

4. Uygulamayı başlatın:
   ionic serve
